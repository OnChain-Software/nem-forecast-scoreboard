NEM Forecast Scoreboard

OnChain Software's 24-hour-ahead price forecasts, scored every day against AEMO's 12:30 pre-dispatch for the five NEM regions.

Each forecast is locked in by hash at 12:45 AEST, before any half-hour it covers begins. It is published and scored once the actual prices are out.

How it is scored

  • Forecast: committed by 13:00 AEST each day for the next 47 half-hours, 13:00 that day to 12:30 the next day, in all five regions. Every half-hour starts after the forecast is locked in.
  • AEMO comparator: AEMO's 12:30 pre-dispatch run on the same day, as published, over the same half-hours. This is the first run after day-ahead bids close.
  • Actual price: the mean of the six 5-minute dispatch prices in each half-hour.
  • Spike score (lower is better): the Brier score for "price above A$300/MWh". OCS publishes a probability. AEMO's forecast counts as 1 if its price is above A$300 and 0 otherwise.
  • Price error (lower is better): mean absolute error in A$/MWh over the 47 half-hours.

Rules

  • Every day is published, including days AEMO wins.
  • A day with no forecast committed on time shows as missed. Missed days are never backfilled, and scored rows are never changed.
  • Before any of its half-hours begins, only the forecast's SHA-256 hash is published, and it is independently timestamped with OpenTimestamps. The forecast file itself is published when it is scored, so anyone can check that it matches the hash. The commit history holds the full record.
  • The scoring rules were fixed at launch. Any change will be noted here with a date, and earlier rows will not be re-scored.
